# Globex SOP — Data export & offboarding requests

## Policy

A full account data export is a **contractual** deliverable, not a
self-serve action. When a customer asks to export all their data (often
while offboarding):

1. Open a ticket in the Legal/Contracts queue with the account name.
2. Reply to the customer with the standard 10-business-day SLA notice and
   the data-processing addendum reference.
3. Never point them at an in-product export button — Globex does not offer
   one for run history.

## What is included

Zaps definitions (JSON), connection metadata (no secrets), and run history
for the retention window in the contract (default 90 days). Attachments are
excluded unless the DPA rider was signed.

## Ownership

Only the account's designated administrator can request an export. Verify
identity against the CRM contact record before starting.
